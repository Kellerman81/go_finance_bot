Strategy (edit & apply live)

Position sizing

Fixed €/$ per buy. Used when "min positions" is 0.
0 = use fixed order size. >0 caps each buy at max_total_invested ÷ this number, so the budget always holds at least this many positions (spreads capital, no all-in-one order).

Holding & confirmation

Minimum time to hold before a strategy sell is allowed (Go duration: 2h, 90m, 0s = off). Protective exits (stop-loss/trailing/take-profit) still fire immediately — this only stops dumping a position seconds after buying.
How many consecutive evaluations must say BUY before buying. 1 = act at once; 2 = wait for a second confirming check.
Consecutive SELL evaluations required before selling, so a single down-tick doesn't trigger an exit.

Protective exits (stops, targets, ladders, time barrier)

Order of precedence: stop-loss → trailing stop → take-profit/ROI → max hold. A downside rule always beats a target in the same move, and the scale-out ladder only runs when none of them fired.

Entries (pyramiding, scale-in, slot policy)

⚠️ Scale-in is averaging down. It improves the entry price of every trade that recovers and increases the size of every trade that does not. Keep max_adds small, keep the stop-loss on, and prove it in a backtest before trusting it with money.
